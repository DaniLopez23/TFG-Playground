# TFG Playground

This repository serves as a sandbox environment to explore and validate the integration of various technologies for the development of a customizable digital twin. The focus is on modeling and analyzing the behavior of milk tanks in the livestock sector.

The goal of this playground is to test the technical feasibility, interoperability, and performance of different components that will be part of the final solution proposed for the final degree project (TFG).

## Purpose

- Experiment with real-time data pipelines (e.g. MQTT, WebSockets)
- Integrate 3D visualization tools (e.g. React Three Fiber, Blender exports)
- Test sensor data simulation and acquisition
- Evaluate frontend and backend communication strategies

> **Note**: This is not the final implementation, but an experimental environment to inform architectural and technological decisions for the TFG project.
